# マルバツゲーム

## 概要

「[一週間で身につくC++言語の基本](https://cpp-lang.sevendays-study.com/)」の基本編を終えてすぐ、初めて自力で制作したゲームです。

ターミナル上でも、視覚的に操作できるようにしたいという意思がありました。（座標を数値で打ち込む形式は認めない）

そのため、マスを描画したり、WASDを使用してカーソルを移動させるロジックに力を入れました。

## 工夫した点

- **カーソルによるマスの上書き防止**
カーソルが移動するとき、移動先のマスをカーソル専用記号(■)が上書きしてしまいます。
そこで、移動の度に既存のマスを`l_grids`という変数に退避させることで、上書きを防ぎました。

- **カーソルの非表示機能**
カーソルの記号が今いるマスの記号を隠してしまうため、確認できないという問題がありました。
そこで、xキーを実行することで一時的にカーソルを非表示にできる仕組みを設けました。

## 感想
人生で初めて、ゼロからコーディングする機会だったので、最初何から手を付ければいいかわかりませんでした。

しかし、大まかなアルゴリズムや設計は頭にあったので、とりあえず変数やメソッドを定義していきます。

そうすると、自然と次に書くべきことが決まっていくので、なんだかんだスムーズに書くことができました。

シンプルに文法がわからなかったことが多かったので、その時はGoogle検索したり、気になったことがあれば搭載されているGeminiなどに質問しました。

書いているときは、「絶対にこの書き方してる人俺だけだろな」とよく考えていました。（極力、「一般的にはどういう風に書くか」というのを調べなかったためでもある）

一切触らなかった日もありましたが、制作8日目にようやく動く形で完成しました。

そのタイミングでいつもお世話になっていたClaude AIに、ここまでのコードをすべて貼り付け、評価をもらいました。

そこで意外だったのがバグが思ったより少なかったということです。

Claudeと会話をしているうちに、改善案がいろいろ見つかり、修正を重ねて、今のコードが完成形です。

過去にWebアプリ開発などを行っていましたが、正直全部AIコーディングといっても過言ではありませんでした。

しかし、なんだかんだAIに一切頼らなくても、自力でコーディングすることができて嬉しかったです。
