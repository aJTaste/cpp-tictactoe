# マルバツゲーム

## 概要

「[一週間で身につくC++言語の基本](https://cpp-lang.sevendays-study.com/)」の基本編を終えてすぐ、初めて自力で制作したゲームです。

ターミナル上でも、視覚的に操作できるようにしたいという意思がありました。（座標を数値で打ち込む形式は認めない）

そのため、マスを描画したり、WASDを使用してカーソルを移動させるロジックに力を入れました。

## 遊び方

1. コンパイル
```bash
   g++ -std=c++17 main.cpp game.cpp -o marubatsu
```
2. 実行
```bash
   ./marubatsu
```

C++17に対応したg++が必要です。

## 操作方法

いずれかのキーを打った後、Enterキーで入力すると実行します。

### アクション

- `c` マスに置く
- `x` カーソルを非表示/再表示

### カーソル移動

- `w` 上に1マス移動
- `a` 左に1マス移動
- `s` 下に1マス移動
- `d` 右に1マス移動

## 工夫した点

- **カーソルによるマスの上書き防止**
カーソルが移動するとき、移動先のマスをカーソル専用記号(■)が上書きしてしまいます。そこで、移動の度に既存のマスを`l_grids`という変数に退避させることで、上書きを防ぎました。

- **カーソルの非表示機能**
カーソルの記号が今いるマスの記号を隠してしまうため、確認できないという問題がありました。そこで、xキーを実行することで一時的にカーソルを非表示にできる仕組みを設けました。

## 学んだこと

### 技術面など

- bool型の変数において、`hide = !hide`のようにすると、真偽を反転させられる
- 配列の中に、それぞれさらに配列を持たせたいときは、`grids[3][3]`のように書ける
- 定数はJavaScriptと同様、`const`を用いて定義できる
- メンバ変数以外にも、ローカル変数というものがある

### 考え方など

- 違いの判らない複数の書き方があって迷ったときは、**処理回数の少なそうな方を選ぶ**とよい
- 実際に頭の中で動かしてみて、**無駄な動作**がないかを見つけるのが大事
- `using namespace std;`は、ヘッダーファイルで定義しない。なぜなら、`#include`で読み込んだファイルすべてに影響してしまうため
- その1つの関数内のみ、などの限定的な場面で使われる変数は、ローカル変数として定義する
- 一方、処理全体で値を保持したい場合などはメンバ変数として定義する
